# HINDI INSURANCE GLOSSARY (Use when language is Hindi or Hinglish)

| English | हिन्दी (Devanagari) | Roman Hindi | Use in replies |
|---|---|---|---|
| Insurance / policy | बीमा / पॉलिसी | bima / policy | "पॉलिसी" is what people say |
| Claim | क्लेम / दावा | claim / daava | Prefer "क्लेम" |
| Premium | प्रीमियम | premium | Keep English loanword |
| Sum insured | बीमित राशि | beemit raashi | Explain: "पॉलिसी में तय अधिकतम कवर" |
| Cashless | कैशलेस | cashless | Explain once: "अस्पताल को सीधे भुगतान" |
| Reimbursement | खर्च की वापसी / रीइंबर्समेंट | kharch ki wapsi | Explain once: "पहले आप भुगतान करते हैं, बाद में पैसा वापस मिलता है" |
| Rejection / repudiation | क्लेम अस्वीकृत / खारिज | claim reject / khaarij | Prefer "क्लेम रिजेक्ट हुआ" |
| Appeal / grievance | अपील / शिकायत | appeal / shikayat | "पुनर्विचार का अनुरोध" for appeal |
| Grievance officer | शिकायत निवारण अधिकारी | shikayat nivaran adhikari | |
| Insurance Ombudsman | बीमा लोकपाल | bima lokpal | |
| Waiting period | वेटिंग पीरियड (प्रतीक्षा अवधि) | waiting period | |
| Pre-existing disease | पहले से मौजूद बीमारी | pehle se maujood bimari | |
| Moratorium (60 months) | मोराटोरियम अवधि (60 महीने) | moratorium | Explain: "इसके बाद सामान्यतः कारण बताकर क्लेम नहीं ठुकराया जा सकता" |
| Co-payment | को-पेमेंट (सह-भुगतान) | co-pay | "क्लेम का कुछ प्रतिशत आपको खुद देना" |
| Deductible | डिडक्टिबल (कटौती योग्य राशि) | deductible | |
| Exclusion | अपवर्जन (जो कवर नहीं है) | exclusion | Say "जो कवर नहीं है" |
| Room rent limit | कमरे के किराए की सीमा | kamre ke kiraye ki seema | |
| Non-payable items | जो भुगतान में शामिल नहीं होते | non-payable items | |
| Consumables | उपभोग्य सामग्री (दस्ताने, मास्क आदि) | consumables | |
| Discharge summary | डिस्चार्ज सारांश | discharge summary | |
| Indoor case papers | इनडोर केस पेपर्स (भर्ती के दौरान का रिकॉर्ड) | indoor case papers | |
| Hospitalisation | अस्पताल में भर्ती | hospital mein bharti | |
| TPA | टीपीए (बीमा कंपनी की ओर से क्लेम देखने वाली संस्था) | TPA | |
| Nominee / legal heir | नामांकित / कानूनी वारिस | nominee / kanooni waaris | |
| Policyholder | पॉलिसीधारक | policyholder | |
| Indicative estimate | संकेतात्मक अनुमान (अंतिम फैसला बीमा कंपनी का) | andaaza | |
